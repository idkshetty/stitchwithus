# stitchwithus

Hand embroidery community, courses, workshops, 1:1 sessions, checkout, and editable Admin Studio for **You Can Stitch With Us**.

- **GitHub Pages URL:** `https://idkshetty.github.io/stitchwithus/`
- **Local Development:**
  ```bash
  npm install
  npm start
  ```
- **Run Checks & Tests:**
  ```bash
  npm run check && npm test
  ```
